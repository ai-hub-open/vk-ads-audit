# vk-ads-audit

> Аудит и быстрый анализ кабинета VK Рекламы (`ads.vk.ru`) — только на чтение. Два режима в одном скилле.

Скилл проводит аудит кабинета VK Рекламы: агент читает кабинет через MCP — подключение агента к рекламной
системе, здесь к VK Рекламе, — находит расход без конверсий, цену результата выше целевой, выгоревшие креативы,
ошибки настройки и лидеров для масштабирования и собирает отчёт с находками по приоритету.

Скилл ничего не меняет в кабинете: он вызывает только инструменты чтения. На просьбу «поставь на
паузу», «удали», «создай» агент прямо отвечает, что только читает кабинет, и подсказывает, где это сделать:
правки и создание — скилл запуска [vk-ads-manager](https://github.com/ai-hub-open/vk-ads-manager) после
вашего «ОК», удаление и запуск — вы сами в кабинете.

## Режимы

- **Глубокий аудит** — разовая диагностика за период (по умолчанию 30 последних полных дней, минимум 14).
  Просьбы вида «сделай аудит VK», «почему дорогой лид», «что отключить».
- **Быстрый анализ** — сводка за вчера или за неделю: 5–10 строк в чат, только аномалии.
  Просьбы вида «как у нас в VK», «сводка VK за вчера», «как прошла неделя». Если найдены аномалии,
  агент предложит глубокий аудит, но сам его не запустит.

Режим скилл выбирает сам по вашей просьбе; если не уверен — спросит одним вопросом.

## Что на выходе

**Глубокий аудит** — файл `АУДИТ_<проект>.html` (открывается в браузере, печатается в PDF) и сводка
в чате на 5–10 строк:

- **чек-лист из семи блоков** с баллом «выполнено / проверено» по каждому: техническая настройка,
  структура кабинета, таргетинг, бюджет и стратегия, объявления, эффективность, воронка после клика
  (по Яндекс Метрике);
- **находки по приоритету** — 🔴 срезать слив → 🟠 починить → 🟢 масштабировать → ⚪ гигиена. У каждой
  названы объект, период, числа, порог и действие: что отключить, что масштабировать, что исправить.
  Например: расход без конверсий, цена результата выше целевой, низкий CTR, выгорание креативов,
  автостратегия без данных для обучения, пустые группы, отклонённые объявления, дубли таргетингов, пиксель;
- **вопросы к клиенту** — то, чего не видно в API (например, используются ли лид-формы или рассылки);
  важные агент задаёт сразу, по одному, и пересобирает чек-лист по ответам;
- **ограничения** — что не удалось проверить и почему; молча упрощённый вывод скилл не выдаёт.

**Быстрый анализ** — несколько строк в чат: итоги дня в сравнении с неделей и отклонения по активным группам.

Все числа считают скрипты скилла по выгрузке из кабинета, агент их не пересчитывает и не придумывает.
Мало данных — в отчёте так и написано.

## Как считается

- **Конверсии — «Результат» VK** по цели оптимизации, как колонка «Результат» в кабинете.
- **Опорный CPA** — целевой CPA клиента; если его нет — медиана CPA живых групп (не удалённых и не в архиве)
  с той же целью, и в отчёте об этом пометка.
- **«Не получено» ≠ «плохо».** Если API не отдал поле, проверка получает статус «—» (нет данных), а не ❌.
- **Только чтение — на уровне кода.** Скрипты ходят в MCP через белый список инструментов чтения
  ([`scripts/mcp_client.py`](scripts/mcp_client.py)); агент тоже вызывает только инструменты чтения.

## Что нужно

- **Кабинет VK Рекламы** (`ads.vk.ru`) с расходом за выбранный период.
- **Подключение VK Рекламы (MCP)** — см. ниже.
- **Запуск Python-кода в среде.** Вся арифметика — в скриптах; без запуска кода скилл не работает и скажет
  об этом прямо. Скриптам нужен только Python 3 со стандартной библиотекой — ставить пакеты не нужно.
- **Яндекс Метрика — по желанию.** С подключением Метрики аудит проверяет, что происходит после клика:
  отказы, достижение целей по трафику из VK.

## Подключение к кабинету

Скилл работает через тот же MCP-сервер VK Рекламы, что и скилл запуска
[vk-ads-manager](https://github.com/ai-hub-open/vk-ads-manager): сервер размещён на стороне click.ru,
разворачивать ничего не нужно. Если VK Реклама у вас уже подключена для vk-ads-manager — повторно
подключать не надо.

Доступ к кабинету даётся одним из двух способов:

- **Через click.ru** — API-токен из профиля [click.ru/userinfo.html](https://click.ru/userinfo.html)
  (поле **API Token**). Кабинет VK Рекламы должен быть подключён в click.ru. Заявка на API VK
  и своё приложение не нужны.
- **Напрямую** — если кабинет заведён не через click.ru: готовый токен доступа VK Рекламы или ключи
  приложения из кабинета (Настройки → API).

Как добавить подключение в Claude Desktop, claude.ai и Claude Code — пошагово в разделе
[«Подключение MCP»](https://github.com/ai-hub-open/vk-ads-manager#подключение-mcp) README vk-ads-manager
и в [`docs/hosted-mcp-setup.md`](https://github.com/ai-hub-open/vk-ads-manager/blob/main/docs/hosted-mcp-setup.md).
Проверка: попросите агента «покажи мои кабинеты VK» — он вызовет `vk_ads_accounts_list`.

**Как идёт сбор данных.** В claude.ai и Claude Desktop агент сам вызывает инструменты чтения и складывает
ответы в рабочую папку; объявления он разбирает у пяти групп с наибольшим расходом — отчёт это
оговаривает. В Claude Code скрипт может собрать данные сам — для этого агент один раз попросит
персональную ссылку подключения и сохранит её вне рабочей папки (`python -m scripts.credentials`);
без ссылки агент собирает данные так же, как в Claude Desktop.

⚠️ Ссылка подключения с токеном равносильна паролю от кабинета: не пересылайте её и не вставляйте
в общие чаты. При утечке пересоздайте токен в профиле click.ru.

## Установка

Скилл ставится из каталога плагинов [claude-plugins](https://github.com/ai-hub-open/claude-plugins) — там же
выбор способа установки ([какой способ выбрать](https://github.com/ai-hub-open/claude-plugins#какой-способ-установки-выбрать))
и включение автообновления.

**Claude Desktop — через интерфейс.** Нужен Git
([как поставить](https://github.com/ai-hub-open/claude-plugins#шаг-1-установите-git)); после его установки
перезапустите Claude Desktop. **Settings → Plugins** → **+ → Add marketplace → Add from repository** →
`https://github.com/ai-hub-open/claude-plugins` → в каталоге **ai-hub-open** нажмите **Add** у
`vk-ads-audit`. Автообновление — переключатель **Auto-update** у каталога там же, в **Settings → Plugins**
([по шагам](https://github.com/ai-hub-open/claude-plugins#установка-в-claude-desktop)).

**Claude Code — командами:**

```
/plugin marketplace add ai-hub-open/claude-plugins
/plugin install vk-ads-audit@ai-hub-open
```

Автообновление включается один раз: `/plugin` → **Marketplaces** → `ai-hub-open` → **Enable auto-update**.

**Архивом (claude.ai, любой тариф).** Скачайте `vk-ads-audit.skill` из блока **Assets**
[последнего релиза](https://github.com/ai-hub-open/vk-ads-audit/releases/latest) (не «Source code»).
Включите **Settings → Capabilities → Code execution and file creation** и загрузите архив в
**Customize → Skills → + → Create skill → Upload a skill**. Файл `.skill` — обычный ZIP; если окно загрузки
его не принимает, переименуйте в `.zip`.

Вызов: `/vk-ads-audit:vk-ads-audit` или просьбой своими словами — «сделай аудит VK», «сводка VK за вчера».
В начале разговора скилл сверяет свою версию с GitHub и скажет, если вышла новая.

Рабочие папки `vk-audits/<проект>-<дата>/` создаются в текущей папке, а не внутри скилла: папка плагина
при обновлении заменяется целиком. Каждый новый аудит — новая папка. Чтобы продолжить прерванный аудит,
скажите «продолжаем аудит VK».

## Ограничения

**Чего скилл не делает:**

- не меняет кабинет — ни паузы, ни правок, ни создания; правки — в
  [vk-ads-manager](https://github.com/ai-hub-open/vk-ads-manager) или вручную;
- не заводит пиксель и не проверяет код на сайте;
- не заменяет таргетолога: находки — основание для решения, решение за маркетологом.

**Чего нет в API VK Рекламы** — эти пункты входят в каждый отчёт:

- нет разрезов по полу, возрасту, гео, площадкам и устройствам — какие аудитории дают конверсии, по ним не определить;
- не видно, срабатывает ли пиксель: ноль конверсий может означать, что пиксель не передаёт события;
- модель атрибуции (post-click или post-view) меняет число конверсий — сверяйте с настройкой кабинета;
- данные за сегодня неполные, поэтому период заканчивается вчерашним днём; дневная статистика хранится
  366 дней;
- статусы ОРД видны частично;
- охват и частота за период доступны не для всех групп — по остальным выгорание по частоте не проверяется;
- размер LAL-сегментов и обновление баз клиентов через API не видны.

Полный список с формулировками — [`references/limitations.md`](references/limitations.md).

| [`references/`](references/) | правила диагностики и пороги, инструменты чтения MCP, связка с Метрикой, вопросы клиенту, шаблон отчёта, ограничения |

## Разработка

```
pip install -r requirements-dev.txt
python -m pytest                 # тесты
python -m evals.run_evals        # эталоны
python -m scripts.make_bundle    # архив vk-ads-audit.skill для релиза
```

Как устроен прогон (пошагово для агента, с кодами выхода — в [`SKILL.md`](SKILL.md)):

```text
предполётка → сбор (raw/) → normalize → dataset.json → [metrika.json] → diagnose → findings.json
           → гейт: сводка и вопросы клиенту в чат → render_report → АУДИТ_<проект>.html
```

Версия должна совпадать в `VERSION`, `.claude-plugin/plugin.json` и первом заголовке `CHANGELOG.md` — это
проверяет CI ([version-check](.github/workflows/version-check.yml)). Без поднятой версии пользователи
плагина изменений не получат.
