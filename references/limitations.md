# Ограничения аудита

## Всегда (в каждом отчёте, дословно — `ALWAYS_LIMITATIONS` в `scripts/render_report.py`)

- В API нет разрезов по полу, возрасту, гео, площадкам и устройствам — «кто конвертит» по ним не определить.
- API не показывает, срабатывает ли пиксель: ноль конверсий может означать сломанный пиксель.
- Атрибуция (post-click или post-view) меняет число конверсий — сверяйте с настройкой кабинета.
- Данные за сегодня неполные — период заканчивается вчерашним днём.
- Статусы ОРД видны частично.

## По прогону (добавляет `limitations` в `scripts/render_report.py`)

- Данные собраны через модель (путь A): объявления разобраны только у групп с наибольшим расходом.
- Объявления не собирались — выводы на уровне групп.
- Метрика не подключена: поведение на сайте после клика не проверялось.
- Метрика без UTM-разметки: склейка только на уровне всего трафика VK, правила по группам не применялись.
- Заметки нормализации (`notes` в `dataset.json`), каждая отдельной строкой:
  - «Объявления не собраны для N групп — по ним выводы на уровне группы.»
  - «Статистика не получена для N групп — итоги и выводы по ним неполные.»
  - «Сумма по объявлениям меньше расхода группы N (часть объявлений удалена?)».
- Не удалось получить `<инструмент>`: `<ошибка>` — по одной строке на каждый неудачный вызов из `collect_log.json`.
- Статистика за период не собрана — выводы по расходу и результату недоступны.
- Пиксели кабинета не проверялись.
- Сбор прерван: `<причина>` — если в `collect_log.json` есть `aborted`.
